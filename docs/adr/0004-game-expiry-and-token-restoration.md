# Finalize idle games and restore only eligible original token charges

The host funds one complete game with one token; guest joining, same-game resume and changing the host's controlling device are free. A host's deliberate departure or End game finalizes play for everyone, while a temporary disconnect keeps the saved game resumable until 24 elapsed hours without meaningful host gameplay activity. Terminal games cannot resume and release remaining active-account claims.

The user selected an automatic return of the original token if a successfully started game ends or expires without any question ever opening. After opening, ordinary ending/inactivity keeps the charge; recover a platform-interrupted game first, and allow staff to restore one token once for a verified unrecoverable failure with a reason. Restorations link to the original host debit rather than erasing it, so automatic expiry and staff handling cannot both compensate the same game. All token sources are nonexpiring. [ADR 0006](0006-one-bank-without-customer-cashout.md) subsequently excludes customer cash-out/purchase refunds; these game-credit restorations remain in scope.
