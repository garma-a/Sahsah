# Fonts

Static instances from Google Fonts, matching the prototype's `@import` in
`sahsah_prototype/src/index.css`. All three families are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org).

| Family | Weights | Use |
| --- | --- | --- |
| Lalezar | 400 | Display headings (`font-display`) |
| Readex Pro | 300–700 | Body text (`font-sans`) |
| Reem Kufi | 500–700 | Numbers (`.num`) |
